# Taller de estado

Ejercicios cortos para practicar `useState`, de menos a más.

## Cómo empezar

```bash
npm install
npm run dev
```

Abre la URL que aparece. A la izquierda está la lista de ejercicios.

## ¿No te funciona en tu computador?

Puedes hacer el taller en el navegador, sin instalar nada. Abre este link, de preferencia en Chrome o Edge:

https://stackblitz.com/github/DEDW2026-React/taller-estado

Espera a que cargue y trabaja ahí mismo. Los tests se corren en la terminal de abajo. Para no perder tu avance, inicia sesión y guarda tu copia con el botón **Fork**.

## Cómo se trabaja

1. Elige un ejercicio en el menú.
2. Abre su archivo en `src/ejercicios/` (el nombre aparece en la página).
3. Busca los comentarios con 🎃 y complétalos, en orden.
4. Guarda y mira el resultado en el navegador.
5. Si te sobra tiempo, haz los 💯 extra.

## Revisa tu trabajo con los tests

```bash
npm test 01     # revisa solo el ejercicio 1
npm test        # revisa todos
```

Cada ✓ es algo que ya funciona y cada × es algo que falta. Antes de completar un ejercicio es normal que los tests fallen. Algunos pasan desde el comienzo, porque revisan cómo parte la pantalla.

Los tests revisan lo que hace tu app, no cómo la escribiste. Que pasen no significa que el código esté perfecto. Por ejemplo, revisa que no hayas modificado el estado directamente.

## Ejercicios

| # | Ejercicio | Practicas |
|---|---|---|
| 01 | Me gusta | `useState` con un número |
| 02 | Ver más / Ver menos | Estado booleano, ternario y `&&` |
| 03 | Anterior / Siguiente | Un número como índice de un arreglo |
| 04 | Buscador | Input controlado y una lista calculada con `filter` |
| 05 | Agregar artista | Arreglo en el estado, spread y formularios |
| 06 | Desafío: memorice | Todo lo anterior junto, sin pasos guiados |
